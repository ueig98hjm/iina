# IINA

The modern media player for macOS.

[Website](https://iina.io) | [Download](https://iina.io/download/) | [Wiki](https://github.com/iina/iina/wiki)

## Features

- Designed natively for macOS
- Powered by mpv media player
- Modern Swift UI with Dark Mode support
- Picture-in-Picture & Touch Bar support
- Customizable UI & key bindings
- Open plugin system

## Building from Source

### Requirements

- macOS 11.0 or later
- Xcode 14.0 or later
- [CocoaPods](https://cocoapods.org)

### Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/iina/iina.git
   cd iina
   ```
2. Install dependencies using CocoaPods:
   ```bash
   pod install
   ```
3. Open `iina.xcworkspace` in Xcode.
4. Build and run the `iina` target.

# IINA

IINA is the modern video player for macOS.

## Features

- Based on mpv, which provides the best decoding capacity on macOS
- Designed with modern macOS features (Touch Bar, Force Touch, Picture-in-Picture, and more)
- Support for almost every video format and codec
- Highly customizable

## Installation

Download the latest release from the [releases page](https://github.com/iina/iina/releases).
